## How I approach projects

- Make state changes, data ownership, and validation rules explicit.
- Build responsive layouts with keyboard access and reduced-motion support.
- Test important behavior and document what the tests do and do not cover.
- Keep setup instructions, demo limitations, and asset attribution close to the code.
